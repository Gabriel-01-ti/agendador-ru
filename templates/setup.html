Plano gratuito

O Render gratuito serve as páginas. O GitHub Actions executa a programação aos domingos, mesmo quando o site está suspenso. Os dias escolhidos ficam cifrados no GitHub.

  1. No Render, abra Environment e cadastre ADMIN_PASSWORD com pelo menos 16 caracteres. É uma senha nova para o painel; o usuário do painel será admin.
  2. Cadastre APP_SECRET com pelo menos 32 caracteres aleatórios. Use o mesmo valor nos Secrets do GitHub.
  3. Configure a persistência: STATE_BACKEND=github, STATE_REPOSITORY=Gabriel-01-ti/agendador-ru e STATE_TOKEN com um token privado que permita ler e gravar o conteúdo apenas desse repositório.
  4. No GitHub, em Settings → Secrets and variables → Actions, cadastre RU_USER, RU_PASSWORD, APP_SECRET e, ao terminar, SCHEDULE_ENABLED=true.
  5. Para receber o aviso gratuito no WhatsApp, ative o CallMeBot para seu próprio número e cadastre CALLMEBOT_PHONE e CALLMEBOT_APIKEY nos Secrets do GitHub.

Salve no Render e aguarde a atualização. Depois entre neste painel com admin e sua nova senha para escolher os dias predefinidos.

O GitHub pode atrasar uma execução agendada. O sistema tenta reservar antes das 16h e encerra novas tentativas às 15h55, no horário de Brasília. A automação só fica ativa depois de cadastrar os Secrets e habilitar a programação.
